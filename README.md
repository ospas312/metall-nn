# МЕТАЛЛ.НН — локальный MVP

Сайт-портфолио мастерской металлоконструкций с интерактивным конструктором навесов.

## Технологии

- Next.js 16, React 19, TypeScript;
- App Router и Server Components;
- Tailwind CSS 4;
- shadcn/ui на базе Radix UI;
- локальный расчёт без авторизации, базы данных, Sites и Cloudflare Workers.

## Архитектура

- `app/` — маршруты, метаданные и композиция страниц;
- `features/canopy-configurator/` — интерактивный пользовательский сценарий;
- `entities/canopy/` — типы, справочники и формула предварительного расчёта;
- `shared/ui/` — локальные компоненты shadcn/ui;
- `shared/lib/` — общие утилиты.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Откройте http://localhost:3000.

Проверка перед изменениями:

```bash
pnpm test
```

Расчёт в MVP является предварительной оценкой, а не рабочей проектной документацией.
